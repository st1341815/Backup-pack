# 备份打包 v1.2.12

飞牛 fnOS 原生应用（FPK）：把大量小文件目录（典型场景：相册缩略图）打包成单个可校验的备份包。

---

## 功能

- **三种格式**：`tar`（默认最快）/ `tar.gz` / `tar.zst`
- **保留 N 份有效包**：只有带 `.sha256` 的包才计入保留份数；打包失败即删残包，不会挤掉好包
- **产物四态**：`完整` / `近似快照`（tar rc=1）/ `未知` / `无效`（缺校验），列表里一眼区分
- **原子锁**：`O_EXCL` 创建 + PID 存活检测 + 60s 心跳；进程被 kill -9 后下一次立即回收，不等时间阈值
- **挂载点守卫**：首次成功记录目标挂载点，外接盘掉线即拒绝写入；先校验后建目录，避免 60GB 写进系统盘
- **空间预检**：按 tar 头部/对齐精确估算 + 10% 余量，keep 份数不足提前告警
- **定时任务**：频率（每天/每周/每月）+ 原生时间控件自动生成 cron；复杂表达式落「高级」手写模式，原值不被改写
- **目录选择**：接入 fnOS 原生选择框（`pickSharedFile` / `pickUserFile` + `api-scope` 应用鉴权），选完自动回填并校验读写权限
- **状态可见**：上次成功时间、距今天数（超期标红）、最近失败原因、锁持有者
- **校验**：`.sha256` 只记 basename，包改名/换机仍可校验

## 安装

1. 应用中心 → 手动安装 → 选 `backup-pack-1.2.12.fpk`
2. 应用「设置 → 授权目录」授权源目录与目标目录
3. 打开应用 → 点「选择…」挑目录 → 保存配置 → 立即备份

**要求**：fnOS ≥ 1.2.0；`/usr/bin/python3` 3.8+；系统 `tar`、`sha256sum`、`crontab`；`zstd` 可选。

## 本版变更（1.2.12）

- 目录选择：侧栏分组补 `storage`（存储空间，管理员视角可见），并开放 `allowToStorageRoot` /
  `allowToStorageSubDir`，使 `/vol2`、`@appdata` 下的目录可选
- 修复：`config/resource` 补 `api-scope` 声明（`trim.file.sharedAccess` / `userAccess` / `userAcl` / `path`），
  否则宿主报「应用鉴权异常」，表现为点按钮无反应
- 修复：区分「用户取消」与「调用失败」——仅在 SDK 不可用 / standalone / 桥不可用时回退内置浏览器
- 修复：`ready()` 增加超时；SDK 改绝对路径动态 import，避免相对路径解析到错误 URL
- 修复：应用入口 `allUsers` 改为 `true`，避免注册成 `is_admin` 导致 FN Connect 提示无权限

## 已知限制

- 只备份缩略图等派生数据，**不含原图**，不能替代原图备份
- `/volN/_sysbackup` 是 fnOS 系统保留区，应用中心不允许第三方应用授权
- 无失败通知（v1.3 计划），靠「上次成功距今 N 天」发现
- cron 无 anacron 语义：到点关机则本次跳过

详见仓库 `KNOWN_ISSUES.md`。
